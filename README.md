reference design for a control surface for [neurogenic](https://github.com/EMajesty/neurogenic).

### Encoders

- 1 data entry, detented (push?)
- 8 parameter, detentless

### Buttons

#### Navigation
left
right
enter
back (home)
(track- (bank-))
(track+ (bank+))
(pattern- (prev variation))
(pattern+ (next variation))

#### Global
shift
select
undo (redo)
save (save as)

#### Modes
seq
sample
slice
mix
fx
song
browse
setup
step
pad
note
(16 levels/notes)

#### Performance/steps
- 16 arcade buttons, "pads", 2x8 matrix

#### Transport
play (restart from beginning)
stop (panic/all off(or double tap/hold))
rec (rec settings)
tap tempo (tempo entry)

#### Performance/edit
fill (latch fill)
copy (duplicate)
paste (paste special)
clear (clear pattern/selection)
(generate (regenerate same seed))
(mutate (new random seed))
XY (select XY pad)

### Modifiers
shift + button: secondary related function
hold button + turn encoder: edit a related parameter
long press button: open settings or details for that function

### Analogs

- 1 master volume potentiometer (global output attenuation, as data)
- 4 parameter faders
- 1 crossfader
